# Sub Test Bench

![License](https://img.shields.io/github/license/l3gatee/subtest-bench)
![GitHub Pages](https://img.shields.io/website?url=https%3A%2F%2Fl3gatee.github.io%2Fsubtest-bench)

Инструмент для перевода и сравнения субтитров через [OpenRouter](https://openrouter.ai) — от быстрого теста «какая модель лучше и дешевле» на паре реплик до перевода целого эпизода с сохранением таймингов.

**[Открыть →](https://l3gatee.github.io/subtest-bench)**

## Зачем это

Перед тем как переводить целый сериал через API, полезно понять на паре реплик:
- какая модель лучше держит тон, юмор и разговорный регистр
- сколько это реально будет стоить на серию из сотен реплик

А когда модель выбрана — перевести весь эпизод сразу, с сохранением таймингов, персонажей и терминологии сериала, без перепечатывания вручную.

## Возможности

**Сравнение моделей**
- Любая модель из каталога OpenRouter — поиск и добавление сколько угодно моделей для сравнения
- Реальные цены подтягиваются напрямую из OpenRouter, не захардкожены
- Любое направление перевода — язык оригинала и перевода задаются свободно (Russian, English, Spanish, German, French и другие), с кнопкой мгновенной смены направления
- Можно вставить кусок `.srt` как есть — номера реплик и тайминги уберутся автоматически
- Построчное сравнение переводов в виде «субтитров» — сразу видно, кто во что превратил одну и ту же фразу
- Расчёт стоимости теста и экстраполяция на целый эпизод

**Контекст сериала**
- Режим «Перевод сериала» хранит контекст (персонажи, их пол, словарь терминов, заметки о стиле) в файле прямо в папке на компьютере — не на сервере
- Открываешь ту же папку для следующего эпизода — контекст подхватывается автоматически
- Быстрое массовое добавление персонажей списком, без сторонних сервисов и регистраций

**Перевод целого эпизода**
- Загружаешь `.srt` целиком — переводится пачками через одну модель, с сохранением оригинальных номеров и таймингов
- Пачки режутся не вслепую по счёту реплик, а по паузам в диалоге (тайминги между репликами), чтобы не разрывать сцену посередине
- Хвост контекста между пачками для связности терминологии и тона
- Промпт перевода редактируемый, с автоматическим добавлением контекста сериала поверх
- Живая таблица «оригинал / перевод», редактируемая перед сохранением
- Кнопка «Остановить» в любой момент — уже переведённое сохраняется
- Если перевод оборвался (вручную или из-за ошибки) — при повторной загрузке того же файла продолжает с места остановки, а не с начала
- После перевода — стоимость в $ и ₽ (курс подтягивается автоматически) и время перевода

## Как запустить

1. Открой [страницу инструмента](https://l3gatee.github.io/subtest-bench)
2. Получи ключ на [openrouter.ai/keys](https://openrouter.ai/keys) — на счету должно быть немного пополнения (перевод пары реплик стоит доли цента)
3. Вставь ключ в поле — он используется только в браузере для прямых запросов к OpenRouter и никуда больше не уходит
4. Для сравнения: выбери модели, вставь реплики, жми «Перевести и сравнить»
5. Для целого эпизода: включи режим «Перевод сериала» (по желанию — для сохранения контекста), загрузи `.srt` в блоке «Перевод всего эпизода» и жми «Перевести файл»

## Технически

Один статический HTML-файл, без бэкенда. Запросы к OpenRouter идут напрямую из браузера пользователя. Сохранение контекста сериала и файлов перевода использует File System Access API — работает в Chrome и Edge на компьютере, не поддерживается в Firefox/Safari и мобильных браузерах (в таких случаях файлы просто скачиваются обычным образом).
