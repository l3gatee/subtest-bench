Ключ OpenRouter
Ключ используется только в этой вкладке для прямых запросов к openrouter.ai из браузера и нигде не сохраняется — при обновлении страницы его нужно будет ввести заново.
Модели для сравнения
Много моделей одновременно — каждая новая добавляет ещё один параллельный запрос и свой расход по ключу. Работает, но проверь, что готов оплатить все сразу.
Реплики для теста (по одной на строку)
Можно вставить .srt как есть — номера реплик и тайминги (00:00:11,761 --> 00:00:13,971) уберутся сами при вставке.
Тест гоняет только эти строки живьём через каждую модель, а стоимость эпизода — экстраполяция по фактическому расходу токенов на строку.
