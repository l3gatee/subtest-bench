Ключ OpenRouter
Ключ используется только в этой вкладке для прямых запросов к openrouter.ai из браузера и нигде не сохраняется — при обновлении страницы его нужно будет ввести заново.
Режим перевода
Контекст сериала (персонажи, словарь терминов, заметки о стиле) хранится в файле subtest-context.json прямо в выбранной папке на твоём компьютере — не на сервере. Открой для каждого сериала свою папку, и при следующем эпизоде программа сама подхватит уже накопленный контекст.
Папка не выбрана
Браузер не поддерживает выбор локальной папки — эта функция работает в Chrome и Edge на компьютере (не в Firefox/Safari, не в мобильных браузерах).

Реплики для теста (по одной на строку)
Можно вставить .srt как есть — номера реплик и тайминги (00:00:11,761 --> 00:00:13,971) уберутся сами при вставке.
Тест гоняет только эти строки живьём через каждую модель, а стоимость эпизода — экстраполяция по фактическому расходу токенов на строку.

Перевод всего эпизода (.srt) с сохранением таймингов
Загружаешь целый .srt файл, программа переводит его пачками через одну выбранную модель, сохраняя оригинальные номера и тайминги. Если что-то оборвётся на середине — прогресс сохраняется, и при повторной загрузке того же файла перевод продолжится с места остановки, а не с начала.
Пачка режется не строго по числу реплик, а по ближайшей паузе в диалоге (тишина между репликами дольше указанного порога) рядом с целевым размером — так разговор не обрывается посередине. Если подходящей паузы долго нет, пачка всё равно принудительно закрывается на ~1.6× от целевого размера, чтобы не упереться в лимит вывода модели.
